# SortingHat

## Usage

download release

**OR**

Run locally:

Required python version：3.9-3.12

1. `pip install -r requirements.txt`

2. `python main.py`


This SortingHat utilizes the scoring mechanism to select the appropriate college for the user. The input of user will be scored by LLM, output as json and calculated. Allows for continuous conversations.
